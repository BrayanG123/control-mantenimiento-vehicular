## Problema Inicial
Los propietarios de motocicletas y vehículos suelen perder de vista el mantenimiento de su vehículo porque llevan el control de forma manual o simplemente de memoria: anotaciones sueltas o el cálculo aproximado de "cuánto falta" para el próximo cambio de aceite. Esto hace que se olviden fechas o kilometrajes clave para el mantenimiento (aceite, llantas, frenos, entre otros), lo que deriva en reparaciones más costosas, desgaste prematuro de piezas y, en algunos casos, fallas mecánicas que pudieron prevenirse. Al no existir un historial accesible desde el celular, el usuario tampoco puede tomar decisiones sobre cuándo y qué mantenimiento realizar a su vehículo.

## Funcionalidades
- Registrar cambios de aceite, llantas, frenos, etc.
- Control de kilometraje.
- Próximo mantenimiento.
- Historial de mantenimiento.
